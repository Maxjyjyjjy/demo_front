# 注册接口 — 后端实现模版（与 `demo_backend` / 前端统一体一致）

本文档供后端实现 **`POST /api/auth/register`** 时对照；响应结构需与 `docs/前端API对接.md` 中 **统一返回体** 一致。

---

## 1. 约定

| 项 | 说明 |
|----|------|
| **路径** | `POST /api/auth/register` |
| **鉴权** | 不需要（与登录相同） |
| **Content-Type** | `application/json` |

### 统一返回体（与全站一致）

```json
{
  "code": 200,
  "msg": "成功",
  "data": {}
}
```

- 成功创建用户常用 **`HTTP 201`**，且 **`code` 与 HTTP 一致为 `201`**（与现有「创建资源」习惯对齐；若团队统一全用 200，则改为 200 + `code: 200` 并告知前端即可）。
- 业务数据在 **`data`**；无业务载荷时可为 **`""`**。
- 前端 `request` 层：仅当 **`code` 为 `200` 或 `201`** 时视为成功并解包 **`data`**。

---

## 2. 请求体

```json
{
  "username": "string",
  "password": "string"
}
```

| 字段 | 规则（建议） |
|------|----------------|
| `username` | 必填；去首尾空格；长度与字符集按产品定（例：3–32 位，允许字母数字与 `_-`） |
| `password` | 必填；最小长度与复杂度按产品定（前端当前校验 **≥8 位**；后端必须再次校验） |

**说明**：`确认密码` 仅前端校验，**不要**求后端接收第二遍密码字段（除非希望服务端再验一次）。

---

## 3. 成功响应

### 3.1 推荐：注册后直接颁发 Token（自动登录）

与登录接口一致，便于前端一次完成注册进入首页。

**HTTP 201**，`code: 201`，`msg` 示例：`注册成功`。

**`data` 对象**（至少其一，与登录兼容）：

| 字段路径 | 说明 |
|----------|------|
| `data.token` | JWT / 访问令牌 |
| `data.accessToken` | 同上 |
| `data.access_token` | 同上 |

可选附加字段（按需）：`user`（`id`、`username`）、`expiresIn` 等。

**示例**

```json
{
  "code": 201,
  "msg": "注册成功",
  "data": {
    "token": "<jwt>",
    "user": {
      "id": 1,
      "username": "newuser"
    }
  }
}
```

### 3.2 备选：仅创建用户，不返回 Token

前端会在注册成功后跳转登录页。

**HTTP 201**，`code: 201`，`msg`：`注册成功`。

**`data`**：可为 **`""`**，或仅含用户信息不含 token：

```json
{
  "code": 201,
  "msg": "注册成功",
  "data": {
    "user": {
      "id": 1,
      "username": "newuser"
    }
  }
}
```

前端逻辑：若 **`data` 中无法解析出 token**，则跳转 **`/login?registered=1`**。

---

## 4. 失败响应

| HTTP / `code` | 典型场景 | `data` | `msg` 示例 |
|----------------|----------|--------|------------|
| 400 | 非 JSON、字段缺失、密码过短等 | `""` | `需要 JSON 请求体`、`用户名与密码必填`、`密码长度不足` |
| 409 | 用户名已存在 | `""` | `用户名已存在` |
| 401 | 一般注册接口不用；若开启邀请码等可扩展 | `""` | 自定 |

错误体仍为统一结构，**`msg` 给前端直接展示即可**。

## 5. Flask 伪代码模版

```python
# 仅作结构参考，按你项目路由/ORM/密码哈希调整

@app.post("/api/auth/register")
def register():
    if not request.is_json:
        return jsonify(code=400, msg="需要 JSON 请求体", data=""), 400
    body = request.get_json(silent=True) or {}
    username = (body.get("username") or "").strip()
    password = body.get("password") or ""
    if not username or not password:
        return jsonify(code=400, msg="用户名与密码必填", data=""), 400
    if len(password) < 8:
        return jsonify(code=400, msg="密码长度不足", data=""), 400
    if User.query.filter_by(username=username).first():
        return jsonify(code=409, msg="用户名已存在", data=""), 409

    user = User(username=username, password_hash=hash_password(password))
    db.session.add(user)
    db.session.commit()

    # 方案 A：直接签发 JWT（推荐，与登录字段一致）
    token = issue_access_token(user)
    return (
        jsonify(
            code=201,
            msg="注册成功",
            data={"token": token, "user": {"id": user.id, "username": user.username}},
        ),
        201,
    )

    # 方案 B：不返回 token
    # return jsonify(code=201, msg="注册成功", data=""), 201
```
